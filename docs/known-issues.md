# WillowTab 问题记录

审查基线为 v1.7.6，来源为 2026 年 11 月 17 日的代码审查、浏览器复现和用户反馈。以下修复收录于 v1.7.7。

## 已修复

| 优先级 | 原问题 | 修复与回归 |
| --- | --- | --- |
| P1 | 多标签页保存可导致壁纸永久丢失 | 设置按字段保存，图库操作在同一 IndexedDB 事务内提交。并行导入、修改标题、轮播和删除均通过。升级测试覆盖旧图片 ID、顺序、内联数据、未引用原图、迁移中止及旧连接释放后重试。[图库迁移](../js/assets.js#L192) · [事务保存](../js/assets.js#L252) |
| P1 | 关闭搜索联想后仍发起关键词请求 | 关闭会取消当前标签页和其他标签页的请求，发送前读取最新开关。商店版还检查当前主机的授权状态。实际扩展验证了缺少权限时的行为，撤权与迟到的授权结果通过模拟回归。[开关与权限](../js/search.js#L252) · [请求入口](../js/search.js#L305) |
| P2 | CRLF 检出时无法构建 Chrome 商店版 | 共享区块以单行标记收尾。LF 和 CRLF 的全新检出均通过构建和打包。[构建边界](../scripts/build-chrome-store.js#L41) |
| P2 | 联想响应与当前输入或焦点不同步 | 改写关键词后立即回车会提交新输入。打开引擎菜单后，晚到的响应保持失效。[取消旧请求](../js/search.js#L290) |
| P2 | 中文输入法组合阶段触发搜索联想 | 浏览器组合输入测试中，拼音阶段暂停请求和联想按键，确认中文后再查询。[输入处理](../js/search.js#L335) |
| P2 | 同名但内容不同的壁纸被跳过 | 同路径下比较最终图像的 SHA-256。回归覆盖同名异图、重复文件和旧图按需补算散列。[导入去重](../js/assets.js#L284) |
| P2 | 壁纸上的联想文字可能难以辨认 | 联想列表采用独立的浅色或深色表面。上白下黑壁纸下，普通、高亮与悬停文字在测试中均达到 4.5∶1，最低实测约 11.15∶1。[联想样式](../css/style.css#L403) |
| P3 | 透明壁纸的对比度估计偏高 | 采样先合成透明像素与页面底色。透明 PNG 的时钟分析值约 6.03∶1，截图实测约 6.08–6.12∶1，搜索控件的普通和悬停诊断值也达到 6∶1。[底色合成](../js/wallpaper-color.js#L116) |
| P3 | 键盘高亮的联想项可能在可视区外 | 480 × 365 的视口中，高亮第八项时联想列表跟随滚动。[高亮更新](../js/search.js#L458) |
| P3 | 打开设置主面板会重复读取图库原图 | 设置主面板对图库原图的额外读取为零。旧图滚入可视范围后才读取原图并生成缩略图，测试中该图只读了一次。[图库加载](../js/settings.js#L1911) |
| P3 | 发布校验会放行损坏的 ZIP 内容 | 校验逐条解压并检查实际内容、CRC 和路径。两个 ZIP 分别破坏 CSS 压缩数据并保留中央目录后，校验均拒绝。[ZIP 校验](../scripts/validate-release.js#L144) |
| P3 | 英文搜索按钮沿用中文提示 | 提交按钮的读屏名称和悬停提示使用现有词典，英文环境显示「Search」。[按钮标记](../newtab.html#L42) |

## 首屏回归基线

- **背景、搜索框和设置入口。** Chrome 商店版和 Edge 通用版的实际新标签页通过延迟数据库初始化的回归。纯色首帧使用保存的颜色与搜索框配色。壁纸从首帧使用磨砂和可用的小预览，原图解码后接替，缺预览时绘制深色底。设置入口放在引擎菜单时，底部齿轮从首帧隐藏。[首屏设置](../js/theme.js#L94) · [原图交接](../js/settings.js#L989) · [按钮位置](../css/style.css#L819)
