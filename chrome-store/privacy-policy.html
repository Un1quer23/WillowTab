WillowTab 隐私政策

生效日期：2026年5月8日 　|　 最后更新：2026年8月11日

一、引言

WillowTab（以下简称"本扩展"）是一款浏览器新标签页替换扩展，由个人开发者 Un1quer（以下简称"我们"）开发和维护。我们高度重视你的隐私和个人信息保护。

本隐私政策旨在向你说明本扩展如何处理你的信息，包括信息的收集、使用、存储和保护方式。请你仔细阅读本政策。安装或使用本扩展，即表示你同意本政策所述的信息处理方式。

二、我们收集什么信息

2.1 我们不收集的信息

WillowTab 开发者不会收集或保存你的姓名、电子邮箱、电话号码、精确地理位置、设备标识符、浏览历史或书签数据。本扩展不建立用户账户，也不使用这些信息进行用户画像或行为跟踪。搜索相关数据的传输方式见第三节。

2.2 本地存储的信息

以下数据通过浏览器本地存储空间（localStorage 与 IndexedDB）仅保存在你的设备上，不会上传至 WillowTab 运营的服务器：

  • 背景模式偏好（纯色 / 壁纸）
  • 自定义背景颜色值
  • 壁纸图片文件，以及名称、相对路径、ID、亮度、复杂度和创建时间等本地元数据
  • 字体、圆角、阴影、遮罩强度、设置按钮位置和自定义标签页标题等界面偏好
  • 显示模式偏好（跟随系统 / 深色 / 浅色）
  • 当前选择的搜索引擎和搜索联想开关
  • 当前壁纸、可读性保护、搜索框样式和壁纸轮播设置

你可以通过卸载本扩展，或使用浏览器提供的扩展数据或网站数据清理功能，删除上述本地信息；具体可用方式取决于你使用的浏览器。

三、网络请求

本扩展仅在以下场景发起网络请求；WillowTab 不运营用于接收或转发这些请求的中转服务器：

3.1 搜索建议

当搜索联想开启时，你在搜索框中输入的关键词会直接发送到当前选择的搜索引擎（Google、百度、Bing 或 DuckDuckGo）以获取自动补全建议。通用版默认开启搜索联想，可在设置中关闭；Chrome Web Store 版默认关闭，只有在你主动开启并授权相应主机权限后才会请求建议接口。提交搜索时，支持“浏览器默认”的版本会通过浏览器的默认搜索服务提交查询；手动选择其他搜索引擎时，关键词会直接发送到该搜索服务。WillowTab 不会主动附加账户标识或设备 ID；所选搜索服务仍会接收查询词以及完成 HTTPS 请求所需的常规网络信息（例如 IP 地址和浏览器请求头），并按照其自身的隐私政策处理这些信息。

四、权限说明

本扩展在浏览器中声明了以下权限，均仅用于实现核心功能：

  • 新标签页覆盖（newtab）：用于替换浏览器默认新标签页，显示 WillowTab 界面。
  • 主机权限（host_permissions / optional_host_permissions）：用于向所选搜索引擎发送搜索建议请求。通用版使用固定主机权限，并提供搜索联想开关；Chrome Web Store 版使用可选主机权限，仅在开启搜索联想时请求，关闭后会撤销。
  • 搜索权限（search，仅 Chrome Web Store 版）：用于通过浏览器的搜索 API 将查询词提交给当前配置的默认搜索服务，并在当前标签页打开结果。

五、第三方服务

  • 本扩展不集成任何第三方统计分析 SDK、广告联盟、用户画像或行为跟踪服务。
  • 搜索建议请求直接发往各搜索引擎的公开 API 接口，各搜索引擎的隐私政策请参见其官方网站。

六、信息安全

所有个性化设置和壁纸数据均存储在浏览器本地沙箱中，受浏览器自身的安全机制保护。WillowTab 不运营用于保存这些设置或壁纸的服务器；搜索建议和搜索提交涉及的查询词则由所选搜索服务处理，其安全和保留方式适用该服务的政策。

你应妥善保管自己的设备，避免他人物理接触导致本地数据被查看。

七、未成年人保护

本扩展不针对未成年人。未成年人应在父母或其他监护人的指导下使用本扩展。

八、政策更新

我们可能根据法律法规变化或功能调整适时更新本隐私政策。更新后的政策将在本页面发布并注明更新日期。重大变更将通过扩展更新说明或 GitHub 仓库通知。
